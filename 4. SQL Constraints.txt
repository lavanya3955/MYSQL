--------------------------------------------------------------------------------------
CONSTRAINTS
--------------------------------------------------------------------------------------

Constraint is used to restrict the data that can be inserted into a table to ensure accuracy and integrity. 
it can be specified while creating/altering the table statement.

Constraints are rules applied to table columns to control and restrict the data stored in a table.


NOT NULL → Column cannot have NULL values
UNIQUE → All values must be different
PRIMARY KEY → Uniquely identifies each row (NOT NULL + UNIQUE)
CHECK → Ensures a condition is satisfied
DEFAULT → Sets a default value if none is given
FOREIGN KEY → Links one table to another (maintains relationship)

NOTE :  DEFAULT works only when column is skipped, not when NULL is given

	PRIMARY KEY = NOT NULL + UNIQUE (strict rule)

	UNIQUE allows multiple NULLs (in MySQL) - Because NULL is not treated as a value. it is missing data. 
	NULL ≠ NULL MySQL treats each NULL as different (unknown)

CASCADE TABLE - CASCADE is one-way (Parent → Child only)

NOTE:In SQL, ON DELETE CASCADE and ON UPDATE CASCADE are referential actions used with foreign key constraints.
They define what happens to the child table rows when a corresponding row in the parent table is deleted 
or updated.

If a row in the parent table is deleted, all corresponding rows in the child table are automatically deleted.

CREATE TABLE Employees (
    emp_id INT PRIMARY KEY,
    email VARCHAR(100) UNIQUE,
    phone CHAR(10) UNIQUE,
    CHECK (phone REGEXP '^[0-9]{10}$')
);


Explanation:

CHAR(10) → Stores exactly 10 characters.
UNIQUE → No duplicate phone numbers.
CHECK → Ensures:
^ = Start of string
[0-9] = Digits only
{10} = Exactly 10 digits
$ = End of string


--- Valid
INSERT INTO Employees VALUES
(1, 'john@gmail.com', '9876543210');

INSERT INTO Employees VALUES
(2, 'mary@gmail.com', '9998887776');

--- invalid----
INSERT INTO Employees VALUES
(3, 'john@gmail.com', '76543210');
