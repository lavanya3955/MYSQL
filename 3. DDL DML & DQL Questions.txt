ALTER COMMAND - PRACTICE QUESTIONS
===============================================================================

Create a database named CompanyDB.

Create a table named Projects with the following columns:

• project_id         INT
• project_name       VARCHAR(100)
• start_date         DATE
• end_date           DATE
• budget             DECIMAL(12,2)
• status             VARCHAR(50)

Perform the following operations:

1. Add a new column client_name VARCHAR(100).

2. Change the budget column data type to DECIMAL(15,2).

3. Rename the column project_name to project_title.

4. Add a new column project_manager VARCHAR(100).

5. Drop the status column.

6. Rename the table Projects to Client_Projects.

7. Display the table structure.

DML (DATA MANIPULATION LANGUAGE)
===============================================================================

Create a database named SalesDB.

Create a table named Orders with the following columns:

• order_id          INT AUTO_INCREMENT PRIMARY KEY
• customer_name     VARCHAR(100)
• product_name      VARCHAR(100)
• order_date        DATE
• quantity          INT
• price             DECIMAL(10,2)
• status            VARCHAR(20)

Perform the following operations:

1. Insert at least 5 sample records.

2. Insert 3 new records by providing values for all columns.

3. Insert 2 records using only:
   • customer_name
   • product_name
   • price

4. Update the status to 'Delivered' where order_id = 2.

5. Update the status to 'Cancelled' where:
   • quantity < 2
   OR
   • price > 5000

6. Increase the price by 10% where status = 'Pending'.

7. Delete the record where order_id = 4.

8. Delete all records where status = 'Cancelled'.

9. Delete all records from the Orders table.

10. Display all records from the Orders table.

DQL (DATA QUERY LANGUAGE)
===============================================================================

Create a database named CollegeDB.

Create a table named Students with the following columns:

• student_id         INT
• first_name         VARCHAR(50)
• last_name          VARCHAR(50)
• age                INT
• gender             VARCHAR(10)
• course             VARCHAR(50)
• city               VARCHAR(50)
• admission_date     DATE

Insert the given sample records into the Students table.

Practice the following queries:

1. Display all records from the Students table.

2. Display first_name, last_name, and course.

3. Display all unique courses.

4. Display only the student_id column.

5. Display only the admission_date column.
