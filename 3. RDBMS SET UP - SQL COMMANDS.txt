My Sql uses different types of languages to interact with Database. these are categorized based on their functions.
DDL 
DML 
DQL
DCL
TCL 

We will use these commands/stmts based on our requirement.
To identify whether it is a ddl, dml, dcl we have sql keywords under each of them.


DDL – Data Definition Language
Used For : Creating and modifying database structures.
Common Commands:  
CREATE – Create new table or database
ALTER – Modify table structure
DROP – Delete table or database
TRUNCATE – Remove all data from a table. permanent loss
---------------------------------------------------------------------------------------------------
DML - Data Manipulation Language
Used For: Managing data inside tables.
Common Commands:
INSERT – Add data
UPDATE – Modify data
DELETE – Remove data - u can get back the original data.

Note : Delete is used to remove the rows from the table, commit & rollback can be performed after delete statement.
 Truncate is used to remove all the rows from the table. Truncate cannot be rolled back.
------------------------------------------------------------------------------------------------------
DQL – Data Query Language
Used For: Retrieving data from the database.
Common Commands:  
SELECT – To fetch records from database
---------------------------------------------------------------------------------------
DCL – Data Control Language
Used For: Managing permissions and access.
Common Commands:  
GRANT – Give permission 
REVOKE – Remove permission
----------------------------------------------------------------------------------------------------
TCL – Transaction Control Language
Used For: Managing transactions (groups of operations).  
Common Commands:  COMMIT – Save changes
ROLLBACK – Undo changes
SAVEPOINT – (partial rollback) Sets a point in a transaction to rollback (A SAVEPOINT is a marker inside a transaction that allows you to roll back part of the transaction, not the entire transaction.)

TCL--------

A transaction = multiple steps done together as one unit

A transaction is a set of one or more SQL statements that are executed as a single unit of work.
It means - If one fails, the entire transaction is rolled back to keep the data correct.”

Transaction example....
Think of filling an online form:

You enter details step by step
If you cancel → everything is lost (ROLLBACK)
If you submit → saved permanently (COMMIT)
Save draft → like SAVEPOINT

Example: Bank transfer has two steps (debit and credit).
Both steps must happen together for correctness.
If one fails, it causes data inconsistency.

In context of db transactions - “ACID properties make transactions in MySQL reliable.
Atomicity means all or nothing,
Consistency keeps data valid, 
Isolation keeps transactions independent, and 
Durability ensures committed data is saved permanently.”

Explanation:

Atomicity: If one of the two queries fails, both updates will be rolled back.
Consistency: The total amount in both accounts will remain the same. 
Isolation: If another transaction is trying to access the same account, it will
wait until this transaction completes.
Durability: After COMMIT, changes will be saved permanently even in case
of a power failure

Delete-
You can delete one row or all rows.
It does NOT reset auto-increment
It is slower (removes row by row)

Example: School Roll Numbers
Last roll number given = 5
Next roll number = 6

Now imagine all students leave the class (like DELETE)

The register is empty now
But teacher remembers last roll number was 5

So when a new student joins:
He gets roll number 6 (not 1)


Truncate-
It removes everything at once
It resets auto-increment
It is faster

Table becomes empty
Next id starts from 1 again

Example: New School Register
Old register had roll numbers 1 to 5

Now school decides to throw away the old register and take a brand new one (like TRUNCATE)

All old records are gone
Even the roll number tracking is reset

So when a new student joins:
He gets roll number 1 (starts fresh)
