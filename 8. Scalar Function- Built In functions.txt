--------------------------------------------------------------------------------------
BUILT IN FUNCTIONS
--------------------------------------------------------------------------------------

Built-in functions in MySQL are predefined functions used to perform operations 
on strings, numbers, dates, and conditions easily.

You can directly use them in queries to perform operations on data without writing your own logic.

Built-in functions = ready-made functions provided by MySQL to perform common tasks like calculations, 
formatting, string operations, etc.

1. String Functions (work on text)
UPPER() → converts text to uppercase
LOWER() → converts text to lowercase
LENGTH() → returns length of string
CONCAT() → joins multiple strings
SUBSTRING() → extracts part of a string
TRIM() → removes leading and trailing spaces
REPLACE() → replaces part of a string
INSTR() → finds position of a substring

2. Numeric Functions (work on numbers)
ABS() → returns absolute (positive) value
ROUND() → rounds a number to nearest value
CEIL() / CEILING() → rounds number up
FLOOR() → rounds number down
MOD() → returns remainder (modulus)
POWER() → raises number to a power
SQRT() → returns square root

3. Date & Time Functions
NOW() → returns current date and time
CURDATE() → returns current date
CURTIME() → returns current time
DATE() → extracts date from datetime
TIME() → extracts time from datetime
YEAR() → extracts year
MONTH() → extracts month
DAY() → extracts day
DATEDIFF() → difference between two dates
DATE_ADD() → Adds a specified time interval to a date and returns the new date.
DATE_SUB() → Subtracts a specified time interval from a date and returns the new date.

4. Control Flow Functions
IF(condition, value1, value2) → returns value1 if condition is true, else value2
CASE → handles multiple conditions (like switch/if-else ladder)
IFNULL(expr, value) → returns value if expr is NULL
NULLIF(expr1, expr2) → returns NULL if both expressions are equal
COALESCE() → returns first non-NULL value

5.Conversion Function
CAST() -used to change a value from one data type to another.

we have many more like trignometry, logarithm functions..

🔹 5. SUBSTRING()
--------------------------------------------------------------------------------------------------------

SUBSTRING(column_name, start_position, length)

✅ Output
ravi      → rav

  Kiran   →   K  (includes spaces)

Extract last 3 letters of name

FROM Employees;


Extract 3 characters from the end of each employee's name.

SELECT name, SUBSTRING(name, -3, 3) AS Last_3_Letters
FROM Employees;


Extract 3 characters starting from the last character of 'ravi'.

SELECT SUBSTRING('ravi', -1, 3);

String:      r   a   v   i
+ Position:  1   2   3   4
- Position: -4  -3  -2  -1
                          ↑
                      Start here (-1)

-1 → Start at i (the last character).
3 → Try to return 3 characters.

But after i, there are no more characters.

Since you're already at the last character, 
MySQL can only return one character (there are no more characters after it).

🔹 1. ABS()
--------------------------------------------------------------------------------------------------------

--------------------------------------------------------------------------------------------------------

-10.5 → -11  
4.7   → 5  
9     → 9  
2.3   → 2

ROUND goes “away from 0”

<---- -12 ---- -11 ---- -10 ---- 0 ---->
Moving away from 0 on negative side → go left
So from -10.5 → go to -11


❓ Q3: Round to 1 decimal place

SELECT value, ROUND(value, 1) FROM Numbers;

-11 → farther from 0

🔹 5. MOD()
--------------------------------------------------------------------------------------------------------

✅ Output

2.3 → 0.3  

4.7 ÷ 2 =2.35
4.7 ÷ 2 = 2 (whole part) + remainder
take the whole part & multiply by 2
2 × 2 = 4
Now subtract:
4.7-4=0.7

🔹 1. IF()
--------------------------------------------------------------------------------------------------------

👉 Works like simple IF-ELSE

IF(condition, value1, value2)

If condition = TRUE → returns value1
If condition = FALSE → returns value2

❓ Q1: Check if salary > 30000

SELECT name, salary,
IF(salary > 30000, 'High', 'Low') AS salary_status
FROM Employees;

✅ Output
Ravi  → Low  
Anu   → High  
Kiran → Low  
Meena → Low  

--------------------------------------------------------------------------------------------------------
🔹 2. CASE
--------------------------------------------------------------------------------------------------------
👉 Multiple conditions (like if-else ladder)

syntax:
CASE 
    WHEN value1 THEN result1
    WHEN value2 THEN result2
    ELSE result
END


Categorize salary:

SELECT name, salary,
CASE
    WHEN salary >= 40000 THEN 'Very High'
    WHEN salary >= 30000 THEN 'High'
    ELSE 'Low'
END AS category
FROM Employees;

✅ Output
Ravi  → High  
Anu   → Very High  
Kiran → Low  
Meena → Low

🔹 4. NULLIF()
--------------------------------------------------------------------------------------------------------

NULLIF() is a MySQL function used to compare two values.

If both values are equal → it returns NULL
If values are different → it returns the first value


Compare salary and bonus

SELECT name, NULLIF(salary, bonus) FROM Employees;

✅ Output
Ravi  → 30000  
Anu   → 40000  
Kiran → 25000  
Meena → 20000  

(No match → original value returned)

Example: where values match in 2 columns;

INSERT INTO Employees VALUES
(5, 'Ravi', 30000, 30000);


INSERT INTO Employees VALUES
(5, 'Ravi', NULL, NULL);

SELECT NULLIF(salary, bonus) FROM Employees;

✅ Output
NULL

5.Conversion Function
--------------------------------------------------------------------------------------------------------

What is CAST()?

👉 CAST() is used to convert a value from one data type to another. 
CAST() is used to convert values during a query, not to permanently change the column datatype.


to permanently change-- 
ALTER TABLE Employees
MODIFY COLUMN salary DECIMAL(10,2);

CAST() is very useful when the stored datatype is not suitable for the operation you want to perform,
but you don't want to permanently change the table structure.

🔹 Syntax
CAST(expression AS datatype)
=-----------------------------------------------------------------------------
🔹 Step 1: Create Table

CREATE TABLE Sales (
    id INT,
    amount VARCHAR(20)
);

-- 🔹 Step 2: Insert Data

INSERT INTO Sales VALUES
(1, '100'),
(2, '200'),
(3, '300');

SELECT * FROM Sales;

✅ Output
1  100  
2  200  
3  300  

MySQL does not recognize INT, varchar inside CAST
It expects types like:
SIGNED
UNSIGNED
DECIMAL
CHAR
DATE, etc.

--------------------------------------------------------------------------------------------------------
🔹 1. CAST to INTEGER

❓ Q1: Convert amount to number

SELECT amount, CAST(amount AS SIGNED) FROM Sales;


✅ Output
100 → 100  
200 → 200  
300 → 300  


Signed & Unsigned
SIGNED = allows both negative and positive values
UNSIGNED = allows only positive values (and 0)

--------------------------------------------------------------------------------------------------------
🔹 2. Use CAST for Calculation

❓ Q2: Add 50 to amount

SELECT amount, CAST(amount AS SIGNED) + 50 FROM Sales;

✅ Output
100 → 150  
200 → 250  
300 → 350  

 Without CAST → it behaves like string 
 With CAST → works as number 

--------------------------------------------------------------------------------------------------------
🔹 3. CAST to DECIMAL

❓ Q3: Convert to decimal

SELECT amount, CAST(amount AS DECIMAL(10,2)) FROM Sales;

✅ Output
100 → 100.00  
200 → 200.00  
300 → 300.00  

--------------------------------------------------------------------------------------------------------
🔹 4. CAST Number to CHAR

❓ Q4: Convert number to string

SELECT CAST(500 AS CHAR);

✅ Output
'500'

--------------------------------------------------------------------------------------------------------
🔹 5. CAST Date

❓ Q5: Convert string to date

SELECT CAST('2024-01-10' AS DATE);

✅ Output
2024-01-10

--------------------------------------------------------------------------------------------------------

🔹 6. CAST DateTime

❓ Q6: Convert string to datetime

SELECT CAST('2024-01-10 10:30:00' AS DATETIME);

✅ Output
2024-01-10 10:30:00

====================================================
SCENARIO 1: NUMBERS STORED AS TEXT
====================================================

Create Table:

CREATE TABLE Employees (
    emp_id INT,
    emp_name VARCHAR(50),
    salary VARCHAR(20)
);

Insert Data:

INSERT INTO Employees VALUES
(101,'John','50000'),
(102,'David','60000'),
(103,'Mary','70000');

View Data:

SELECT * FROM Employees;

Requirement:
Increase salary by 10%

Query:

SELECT
    emp_name,
    CAST(salary AS DECIMAL(10,2)) * 1.10 AS NewSalary
FROM Employees;

Why CAST?
salary is stored as VARCHAR but calculation requires numeric datatype.

====================================================
SCENARIO 2: DATES STORED AS TEXT
====================================================

Create Table:

CREATE TABLE Orders (
    order_id INT,
    order_date VARCHAR(20)
);

-- Insert Data:

INSERT INTO Orders VALUES
(1,'2025-06-20'),
(2,'2025-07-15'),
(3,'2025-08-10');

Requirement:
Extract Year

Query:

SELECT
    order_id,
    YEAR(CAST(order_date AS DATE)) AS OrderYear
FROM Orders;

SELECT
    order_id,
    CAST(order_date AS DATE) AS OrderYear
FROM Orders;

Why CAST?
YEAR() works on DATE datatype.

====================================================
SCENARIO 3: CONCATENATING NUMBER AND TEXT
====================================================

Create Table:

CREATE TABLE EmployeeMaster (
    emp_id INT,
    emp_name VARCHAR(50)
);

Insert Data:

INSERT INTO EmployeeMaster VALUES
(101,'John'),
(102,'David');

Query:

SELECT
    CONCAT('Employee ID : ', CAST(emp_id AS CHAR)) AS Details
FROM EmployeeMaster;

Output:

Employee ID : 102

Why CAST?
Converts numeric value into text.
