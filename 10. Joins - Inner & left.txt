--------------------------------------------------------------------------------------
JOINS
--------------------------------------------------------------------------------------

Joins in MySQL are used to combine rows from two or more tables based on a related column, 
such as INNER, LEFT, RIGHT, CROSS, and SELF joins.


INNER JOIN → returns only matching rows from both tables
LEFT JOIN (LEFT OUTER JOIN) → returns all rows from left table + matching rows from right table
RIGHT JOIN (RIGHT OUTER JOIN) → returns all rows from right table + matching rows from left table
CROSS JOIN → returns all possible combinations (Cartesian product)
SELF JOIN → joins a table with itself

--------------------------------------------------------------------------------------
In real-world databases, data is stored in multiple tables
to avoid duplication.

Example:
Instead of storing department name again and again,
we store it in a separate table.

So, to get complete information → we use JOIN.

WHEN TO USE JOINS?
----------------------------------------------------------
- When data is stored in multiple tables
- When we need combined information
- When using foreign key relationships

----------------------------------------------------------
IMPORTANT POINTS
----------------------------------------------------------
- JOIN works using common column
- Always use ON condition
- Avoid wrong joins → may give wrong data
- Use table aliases for readability

REAL-TIME EXAMPLE
----------------------------------------------------------

Table 1: Employees
--------------------------------
emp_id | name   | dept_id
1      | Ravi   | 101
2      | Anu    | 102

Table 2: Departments
--------------------------------
dept_id | dept_name
101     | HR
102     | IT

----------------------------------------------------------
PROBLEM
----------------------------------------------------------
We want:
emp_id | name | dept_name

But dept_name is in another table

----------------------------------------------------------
SOLUTION USING JOIN
----------------------------------------------------------

SELECT e.emp_id, e.name, d.dept_name
FROM Employees e
JOIN Departments d
ON e.dept_id = d.dept_id;

e = alias for Employees table
d = alias for Departments table

| Concept               | `AS` alias    | `E.column`            |
| --------------------- | ------------- | --------------------- |
| Purpose               | Rename column | Refer to column       |
| Used in               | SELECT        | SELECT / JOIN / WHERE |
| Changes output name?  | ✅ 		| ❌ No                  |


----------------------------------------------------------
OUTPUT
----------------------------------------------------------
1 | Ravi | HR
2 | Anu  | IT

----------------------------------------------------------
ADVANTAGES OF JOINS
----------------------------------------------------------
- Combines data from multiple tables
- Avoids data duplication
- Improves database design
- Helps in meaningful data retrieval

🔹 1. INNER JOIN
--------------------------------------------------------------------------------------
👉 Only matching rows from both tables

Step 1: Create Tables

CREATE TABLE Employees (
    emp_id INT,
    name VARCHAR(50),
    dept_id INT
);

CREATE TABLE Departments (
    dept_id INT,
    dept_name VARCHAR(50)
);

🔹 Step 2: Insert Data

INSERT INTO Employees VALUES

(2, 'Anu', 20),
(3, 'Kiran', 30),
(4, 'Meena', NULL);

INSERT INTO Departments VALUES
(10, 'IT'),
(20, 'HR'),
(40, 'Finance');

🔹 View Tables

Employees
1 Ravi   10  
2 Anu    20  
3 Kiran  30  
4 Meena  NULL  

Departments
10 IT  
20 HR  
40 Finance  

SELECT emp_id, E.name as e_id, D.dept_name as d_id
FROM Employees E
JOIN Departments D
ON E.dept_id = D.dept_id;


❓ Q1: Show employees with department

SELECT emp_id, E.name as e_id, D.dept_name as d_id
FROM Employees E
INNER JOIN Departments D
ON E.dept_id = D.dept_id;

✅ Output
Ravi → IT  
Anu  → HR  

👉 Kiran (30) → no match 
👉 Meena (NULL) → no match

Q2. Display the student name and the course they are enrolled in
Show only those students who have a matching course

Example 1: Students & Courses
🔹 Create Tables
CREATE TABLE Students (
    student_id INT,
    name VARCHAR(50)
);

CREATE TABLE Courses (
    course_id INT,
    student_id INT,
    course_name VARCHAR(50)
);
🔹 Insert Data
INSERT INTO Students VALUES
(1, 'Ravi'),
(2, 'Anu'),
(3, 'Kiran');

INSERT INTO Courses VALUES
(101, 1, 'Math'),
(102, 2, 'Science'),
(103, 4, 'English');

🔹 Query (INNER JOIN)

SELECT S.student_id, S.name , C.course_name 
FROM Students S
INNER JOIN Courses C
ON S.student_id = C.student_id;



✅ Output

Ravi → Math
Anu → Science

👉 Kiran not shown (no course)
👉 student_id 4 ignored (no student)

Q3.Display the customer name and their order amount
👉 Show only those customers who have placed orders

CREATE TABLE Customers (
    customer_id INT,
    name VARCHAR(50)
);

CREATE TABLE Orders (
    order_id INT,
    customer_id INT,
    amount INT
);

INSERT INTO Customers VALUES
(1, 'Amit'),
(2, 'Neha'),
(3, 'John');

(201, 1, 500),
(202, 2, 700),
(203, 4, 300);

---

🔹 LEFT JOIN

👉 All rows from LEFT table + matching rows from RIGHT table
👉 If no match → NULL values

---

CREATE TABLE Employees (

);
