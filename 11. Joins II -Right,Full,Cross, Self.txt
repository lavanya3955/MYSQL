🔹 3. RIGHT JOIN
--------------------------------------------------------------------------------------
👉 All rows from RIGHT table + matching rows from LEFT table
👉 If no match → NULL values

--------------------------------------------------------------------------------------
Q1: Show employees with their department (include all departments)

🔹 Create Tables
CREATE TABLE Employees (
emp_id INT,
name VARCHAR(50),
dept_id INT
);

CREATE TABLE Departments (
dept_id INT,
dept_name VARCHAR(50)
);

🔹 Insert Data
INSERT INTO Employees VALUES
(1, 'Ravi', 10),
(2, 'Anu', 20),
(3, 'Kiran', 30);

INSERT INTO Departments VALUES
(10, 'IT'),
(20, 'HR'),
(40, 'Finance');

🔹 Query
SELECT E.name, D.dept_name
FROM Employees E
RIGHT JOIN Departments D
ON E.dept_id = D.dept_id;

✅ Output
Ravi  → IT
Anu   → HR
NULL  → Finance

 4. CROSS JOIN
--------------------------------------------------------------------------------------
👉 Combines every row from LEFT table with every row from RIGHT table
👉 No condition needed (Cartesian Product)

--------------------------------------------------------------------------------------

5.FULL JOIN (FULL OUTER JOIN)
--------------------------------------------------------------------------------------
👉 All rows from LEFT table + all rows from RIGHT table
👉 Matching rows are combined
👉 No match → NULL values on either side

⚠️ Note: MySQL does NOT support FULL JOIN directly
👉 Use UNION of LEFT JOIN + RIGHT JOIN

--------------------------------------------------------------------------------------

Q1: Show employees with department (include all employees and departments)

🔹 Create Tables
CREATE TABLE Employees (
emp_id INT,
name VARCHAR(50),
dept_id INT
);

CREATE TABLE Departments (
dept_id INT,
dept_name VARCHAR(50)
);

🔹 Insert Data
INSERT INTO Employees VALUES
(1, 'Ravi', 10),
(2, 'Anu', 20),
(3, 'Kiran', 30);

INSERT INTO Departments VALUES
(10, 'IT'),
(20, 'HR'),
(40, 'Finance');

🔹 Query (FULL JOIN using UNION)
SELECT E.name, D.dept_name
FROM Employees E
LEFT JOIN Departments D
ON E.dept_id = D.dept_id

UNION

SELECT E.name, D.dept_name
FROM Employees E
RIGHT JOIN Departments D
ON E.dept_id = D.dept_id;

✅ Output
Ravi  → IT
Anu   → HR
Kiran → NULL
NULL  → Finance

🔹 6. SELF JOIN
--------------------------------------------------------------------------------------


👉 A table is joined with itself Using aliases (like A, B).
👉 Used to compare rows within the same table

SQL doesn’t have a keyword called SELF JOIN.

So you still must choose a join type:

INNER JOIN
LEFT JOIN
(rarely RIGHT/FULL)

Employees = People
Managers = Boss

| Situation                             | Join to use |
| ------------------------------------- | ----------- |
| Show only people who have a boss      | INNER JOIN  |
| Show everyone (even CEO without boss) | LEFT JOIN   |

Q1: Show employee name and their manager name

🔹 Create Table
CREATE TABLE Employees (
emp_id INT,
name VARCHAR(50),
manager_id INT
);

🔹 Insert Data
INSERT INTO Employees VALUES
(1, 'Ravi', NULL),
(2, 'Anu', 1),
(3, 'Kiran', 1),
(4, 'Meena', 2);

select * from employees;
+--------+-------+------------+
| emp_id | name  | manager_id |
+--------+-------+------------+
|      1 | Ravi  |       NULL |
|      2 | Anu   |          1 |
|      3 | Kiran |          1 |
|      4 | Meena |          2 |
+--------+-------+------------+

🔹 Query (SELF JOIN)
SELECT E.name AS Employee, M.name AS Manager
FROM Employees E
LEFT JOIN Employees M
ON E.manager_id = M.emp_id;


✅ Output
Ravi  → NULL
Anu   → Ravi
Kiran → Ravi
Meena → Anu

Q3: Show employees and colleagues in same department

🔹 Create Table
CREATE TABLE Employees (
emp_id INT,
name VARCHAR(50),
dept_id INT
);

🔹 Insert Data
INSERT INTO Employees VALUES
(1, 'Ravi', 10),
(2, 'Anu', 10),
(3, 'Kiran', 20);

🔹 Query (SELF JOIN)
SELECT E1.name AS Employee, E2.name AS Colleague
FROM Employees E1
JOIN Employees E2
ON E1.dept_id = E2.dept_id
AND E1.emp_id <> E2.emp_id;

✅ Output
Ravi → Anu
Anu  → Ravi

👉 Kiran not shown (no colleague)
