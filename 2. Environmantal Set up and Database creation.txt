Basic commands in Command line client:
---------------------------------------------------------------------------------------------------
show databases;

Default databes:
+--------------------+
| Database           |
+--------------------+
| information_schema |
| mysql              |
| performance_schema |
| sys                |
+--------------------+


information_schema → stores database structure (tables, columns, metadata)
mysql → stores users, passwords, and permissions
performance_schema → stores performance and execution details
sys → provides easy-to-read performance reports

performance_schema collects raw performance data about MySQL activities
This shows:
Queries executed
How many times they ran
Average execution time
Total execution time


use information_schema ;
show tables;

create database databasename;

Database names should be unique and follow naming rules (no spaces, no special characters).

DATA Types: 

Numeric -tiny int/small, int, bigint, decimal, float, double 
String - char,varchar,blob (binary large object - images, videos, audios, pdf documents),text
Date and Time -date,datetime,time,timestamp,year.


-----Numeric-----
tinyint - Stores very small numbers - 1 byte (255 numbers) - ex:age,ratings
int - stores medium numbers - 4 bytes - That is about 2 billion range - ex:salary, IDs
bigint - stores large numbers - 8 bytes - 9 quintillion - ex large IDs, big calculations

| Bytes   | Data Type | Range (approx)              | Digits          |
| ------- | --------- | --------------------------- | --------------- |
| 1 byte  | TINYINT   | 0 to 255                    | 1–3 digits      |
| 4 bytes | INT       | ~2 billion                  | up to 10 digits |
| 8 bytes | BIGINT    | very large (~9 quintillion) | up to 19 digits |

Signed & Unsigned
SIGNED = allows both negative and positive values
UNSIGNED = allows only positive values (and 0)


DECIMAL → exact value (like money) ex:: DECIMAL(10, 2) ------ 10 [overall it takes 10 digits , in that 2 are for digits after decimalpoint]
= whole number part wil take 8 digits, 2 digits after the decimal..

FLOAT → approximate values(like measurements 📏 - temparature) -- 36.6789123 --- rounded to 36.678913
DOUBLE → more accurate approximation ---- Measuring Distance in Space


-----String-----

Char - Fixed length like gender, ex:char(10) it'l reserve the space for 10 characters
varchar -  Variable length,  varchar(10) - stores only what is needed

| Feature | CHAR            | VARCHAR         |
| ------- | --------------- | --------------- |
| Length  | Fixed           | Variable        |
| Space   | Wastes space    | Saves space     |
| Speed   | Slightly faster | Slightly slower |


------ DATE ------

DATETIME-can store date & time
TIMESTAMP-can store date & time but auto updates 
i.e - You create a record → time stored
You update the record → time updates again automatically

DEFAULT CURRENT_TIMESTAMP -  2026-04-03 14:25:10
